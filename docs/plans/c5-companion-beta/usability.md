# Voluntary small-group usability script and blank record

Prepared 2026-10-09. **Not run with participants.** No invitations or messages were sent. Use only after the [readiness prerequisites](beta-readiness.md) and owner authorization. Synthetic browser acceptance is separate evidence.

Ask permission to observe and take notes; explain that the interface is being tested and that stopping or skipping any task is welcome. Do not collect passwords or unnecessary personal data. Offer a separate disposable sample account per participant and a synthetic GOOD file; importing their own game data is optional. Agree on note retention and a feedback contact before starting. No shared writable guest account.

Suggested session: about 15–20 minutes, with actual time recorded rather than assumed. Avoid coaching until the participant asks or stops; record any help supplied. Tasks are voluntary, not success quotas.

1. Without importing, find the supported server choice, choose a routine that matters to you, and record it. Explain what you would do if your server were unsupported.
2. With a supplied sample export if willing, preview the selected sections and explain what will be replaced versus retained. Confirm and find a character's recorded equipment. Describe what an unrecorded slot and an import receipt mean.
3. Choose a focus character and create a goal. Return to Today, open the exact goal, pause/resume it and explain whether removing focus would do the same thing.
4. Dismiss and restore work. Re-import a partial sample. Explain what changed and whether the goal was automatically completed.
5. In a facilitator-controlled disposable failure scenario, type a preference and encounter a failed save. Explain what is saved, what is still a draft and how to recover. No real network or system setting changes are needed.
6. On the participant's preferred device/input method, find settings/import and one secondary tool. If comfortable, repeat navigation using the keyboard, normal browser zoom and their motion/accessibility preferences. Note inaccessible controls and confusing copy.

Close with: What felt useful? What was unclear or unnecessary? What would make you hesitate to trust the records? Would you voluntarily return, and for what task? Record the person's own wording with permission. Do not convert suggestions directly into C6/C7 scope before reviewing the evidence.
