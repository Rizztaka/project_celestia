# C5b readiness checkpoint

The [C5a assessment](../c5a-beta-foundation/beta-readiness.md) remains historical.
This checkpoint adds local synthetic recovery tooling and measured restore/read
evidence. It does not certify production recovery, introduce account export or
authorize a beta invitation/release. All dates/results refer to local Windows work.

| Gate                              | C5b evidence or limit                                                                                                                                                             | Required next evidence                                                                                                                                                        |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Local synthetic recovery          | Guarded full PostgreSQL archive/restore, complete table and history comparisons, real application reads, negative cases and fresh-resource repeat; see validation and walkthrough | Independent review of this bounded implementation and its actual evidence                                                                                                     |
| Production accountability         | No operator/support contact was invented                                                                                                                                          | Name an accountable operator and supported incident/recovery contact                                                                                                          |
| Retention and access              | Run artifacts are private local synthetic files, retained only for inspection                                                                                                     | Decide documented retention, access/revocation, encryption and audit policy                                                                                                   |
| Backup location/provider          | No provider service, bucket or paid infrastructure configured                                                                                                                     | Choose/authorize actual backup location/provider and demonstrate access and failure handling                                                                                  |
| Backup cadence                    | No schedule, WAL archive or ongoing production backup configured                                                                                                                  | Establish and observe the actual backup cadence, monitoring and failure response                                                                                              |
| Acceptable loss/recovery time     | Local milliseconds and small archive sizes are measurements only                                                                                                                  | Owner sets acceptable data loss and recovery time; do not infer RPO/RTO from this fixture                                                                                     |
| Representative production restore | No production data was connected, copied or restored                                                                                                                              | Separately authorize isolated restoration of a representative production backup; verify ownership, history/receipts/choices and dependencies; measure actual outcome/duration |
| Account-data controls             | Database recovery is not account export/deletion/recovery/token revocation                                                                                                        | Scope and test supported user-data and account procedures with assigned ownership                                                                                             |
| Abuse controls                    | CORS remains inherited; no request/signup/import quotas introduced                                                                                                                | Inspect provider controls and implement/exercise the separately scoped bounded controls                                                                                       |
| CI and deployed origins           | No remote run, deployment or production/preview domain configuration                                                                                                              | After separate authorization, observe exact-SHA remote CI and deployed allowed/denied/login/preflight behavior                                                                |
| Accessibility                     | No product UI or new assistive-tool evidence in C5b                                                                                                                               | Actual 200%/400% zoom, rendered reduced motion and assistive-technology assessment                                                                                            |
| Data upkeep                       | Supported game data/clock/contracts unchanged; every production farming route remains unavailable                                                                                 | Accountable maintainer, review cadence and tested disable/rollback procedure                                                                                                  |
| Voluntary beta                    | No participant contacted or invited                                                                                                                                               | Close required gates, obtain invitation authorization and collect actual consenting-user feedback                                                                             |
| C6/C7                             | Not started                                                                                                                                                                       | Separate scope and real-use evidence; no automatic continuation                                                                                                               |

Production recovery also requires deployment/configuration knowledge, global
roles/ACLs, secrets, external assets and any provider-specific dependencies absent
from a single application database archive. Successful local recovery does not
close the coordinated migration/API/frontend cutover gate.
