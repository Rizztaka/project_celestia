# Build Intelligence Engine

When instructed to create a new module in the Intelligence Core (Phase 4), you must strictly follow these rules:

## 1. Directory Structure
The Intelligence Core modules belong under `apps/api/src/games/<game>/intelligence/`.
Create a dedicated folder for the engine (e.g., `team-intelligence/`).

## 2. Core Principles
- **Deterministic**: The calculations must produce the exact same result given the same input state. Do not use randomness unless specifically instructed for a Monte Carlo simulation.
- **Separation of Concerns**: The module must separate "Calculations" from "Explanations".

## 3. Implementation Steps
Create the following files:

### `<engine>.calculator.ts`
Write pure functions that take in player data (Characters, Artifacts, Weapons) and return a numeric score or structured recommendation. This file must NOT contain any string explanations or UI-facing text.

### `<engine>.explainer.ts`
Write functions that take the results from the calculator and generate human-readable string arrays explaining *why* the recommendation was made. 

### `<engine>.service.ts`
Orchestrate the process. Call the Calculator, then pass the result to the Explainer. Return an object that looks exactly like this to the controller:
```typescript
{
  recommendation: T,
  score: number,
  explanations: string[] // Generated by the explainer
}
```

## 4. Never Hallucinate Data
Only use the data explicitly present in the player's account or the static JSON files. If data is missing, the engine must return a graceful error or skip the recommendation, rather than assuming default values.
