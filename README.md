# Project Celestia (v2)

A fast, lightweight, client-first Genshin Impact companion tool focused strictly on **Speed + Accuracy**.

## Core Philosophy
- **Zero Server Overhead:** 100% client-side execution. Zero cold starts, zero sleeping databases, zero mandatory logins.
- **Accurate & Inclusive:** Direct archetype & reaction synergies. Every character—including newly released characters like Nefer—is fully selectable and supported from Day 1.
- **Player-First Focus:**
  1. **Best Team Generator:** Smart, instant team synergy recommendations.
  2. **Account-Aware Pull Advisor:** Recommendations that respect your current owned roster (no advising characters you already own).
  3. **Endgame Guidance:** Abyss & Imaginarium Theater stage planning and shield counters.
  4. **Artifact Stop-Point Calculator:** Clear diminishing returns curves so you know when farming is no longer worth your resin.
