# Today domain schedule — first review version

The connected Today page now has separate Talents and Weapons panels below its compact heading and navigation shortcuts. Material artwork, region, domain entrance, and matching characters/weapons use the existing pinned progression and artwork catalogs. Build chips open the existing UID character detail route. The previous large welcome hero remains available for first-time visitors and the original authenticated workspace; it no longer pushes the connected Today content below the fold.

The server selector starts from supported UID ranges. The schedule uses that server's fixed UTC offset and a 04:00 day boundary, rather than the browser's weekday. A separate ticking countdown avoids re-rendering the material lists every second. The live day follows reset and window focus; selecting a weekday pins the browsing day until Back to today. Sunday exposes every standard material family. Your roster filters against previously observed characters, including retained observations, and their recorded weapons. All materials is available to guests and empty rosters. Long lists start at four families per section and expand independently.

`build-today-domains.mjs` derives game-ID-to-domain matches offline from `progression-catalog.json`; the existing catalog rebuild also regenerates this projection. No name matching, invented inventory, resin estimates, missing counts, or new API requests are introduced. Traveler talent costs are absent from the existing catalog and deliberately remain unmapped. Unknown IDs remain unmapped; Columbina has a regression. The UI identifies the schedule as the standard rotation and notes that temporary game notices and domain unlock requirements take precedence. It does not claim to track event overrides.
