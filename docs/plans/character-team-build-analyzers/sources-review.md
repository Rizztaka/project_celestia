Furina's presence is one reviewed way to enable Skirk's Hunter pattern. Its absence does not prove all HP-change mechanisms impossible; the explanation names this limitation. Element composition verifies prerequisites only, never an active buff.

The interrupted draft's unsupported modern-character profiles were removed from executable coverage. Skirk's talent ordering and Xilonen's artifact direction were corrected. Iansan, Varesa, Escoffier, Dahlia, Ineffa, Lauma, Nefer and Columbina have general checks until their own sources and conditions are reviewed. No matching by display-name resemblance occurs.

Equipment identity is generated from the inherited pinned Enka relic-item mapping and committed profile-reference metadata. It links numeric artifact item IDs to sets and numeric weapon IDs to type/name. Existing metadata attribution remains with those source files. An unknown item or source update stays unresolved rather than receiving a guessed identity.

Run `apps/api/tooling/build-analysis-sources.mjs` only when intentionally refreshing the pinned acquisition. It updates `sources.json` and generated equipment identity, **not** `reviewed-hashes.json`. Review guide changes and relevant tests before accepting fingerprints. A mismatched source disables only the linked profile's tailored findings. No claim is made that guides cannot change after this review.
